## 🚀 Öne Çıkan Projeler

### 🧠 [NTT DATA Sustainability Reports RAG System](https://github.com/furkan-cyber/ntt-sustainability-rag)
> **Production-ready RAG sistemi** — NTT DATA sürdürülebilirlik raporlarını zekice sorgulayan gelişmiş bir yapay zeka uygulaması.

**Özellikler:**
- 🔍 **Multi-Strategy Retrieval:** Vector Similarity + BM25 + HyDE + Multi-Query
- 🤖 **Agentic Framework:** Karmaşık sorguları yönetmek için akıllı ajan sistemi
- 📊 **Real-time Monitoring:** Prometheus metrikleri ve sağlık kontrolleri
- 🌐 **Dual Interface:** REST API (FastAPI) + Gradio web arayüzü
- 🐳 **Full Containerization:** Docker + Docker Compose + Kubernetes desteği
- 🔄 **CI/CD Pipeline:** GitHub Actions otomasyonu
- 🧪 **%90+ Test Coverage:** Kapsamlı pytest test paketi

**Tech Stack:** `Python` `FastAPI` `ChromaDB` `LangChain` `Ollama` `Docker` `Prometheus` `Gradio`
